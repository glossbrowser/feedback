# Gloss Browser feedback

Help make Gloss Browser better:

- [Report a bug](https://github.com/glossbrowser/feedback/issues/new?template=bug.yml)
- [Ask a question](https://github.com/glossbrowser/feedback/issues/new?template=question.yml)
- [Suggest an idea and vote on ideas](https://github.com/glossbrowser/feedback/discussions/categories/ideas)

Search existing posts first. For a bug, tell us what happened, what you expected, how to reproduce it, and your Gloss Browser and macOS versions. Please remove private information from anything you post.

Help › Send Feedback… currently opens an email draft with your Gloss Browser and macOS versions; you decide whether to send it. When the in-app feedback form is enabled, it will submit the type, title, message, and those versions after you review them. A contact email is optional and stays private. Diagnostics are optional; if included, their redacted text appears in the public Issue or Discussion. The form does not collect page content or browsing history.

For security concerns, use [private vulnerability reporting](SECURITY.md).
